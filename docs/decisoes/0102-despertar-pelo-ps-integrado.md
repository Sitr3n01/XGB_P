# 0102 — Despertar pelo PS integrado

- **Status:** Aceita; portada para a candidata pública 3.0.0.
- **Data:** 2026-11-08

## Contexto

O diagnóstico deve mostrar a prontidão para despertar sem mudar a política do PC.

## Decisão

Exibir Acordar pelo PS nas Configurações e na confirmação de suspensão. Os scripts de política são executados pelo usuário; o app só diagnostica. A ADR 0114 define a seleção por instância, o backup e a correlação por ciclo.

Ver [despertar pelo PS](../guias/despertar-pelo-ps.md).

## Validação e limites

A build pública mantém produto e testes separados. Suítes com substitutos não comprovam controle, TV, Steam, áudio ou energia físicos. A publicação no GitHub e a matriz física permanecem pendentes. Ver [comparação e validação do porte](../atualizacao-publica-2026-11-08.md).
