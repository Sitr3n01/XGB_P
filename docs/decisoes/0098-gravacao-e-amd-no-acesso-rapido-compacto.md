# 0098 — Gravação e AMD no Acesso rápido compacto

- **Status:** Aceita; portada para a candidata pública 3.0.0.
- **Data:** 2026-11-08

## Contexto

Captura e ajustes gráficos precisam de destinos próprios na Home.

## Decisão

Gravação abre a captura ReLive e AMD abre os ajustes ADLX. Reutilizar os ícones dos painéis. A distribuição intermediária de oito quadrados foi substituída pela ADR 0099.

## Validação e limites

A build pública mantém produto e testes separados. Suítes com substitutos não comprovam controle, TV, Steam, áudio ou energia físicos. A publicação no GitHub e a matriz física permanecem pendentes. Ver [comparação e validação do porte](../atualizacao-publica-2026-11-08.md).
