# 0096 — Pesquisa de programas pelo Acesso rápido

- **Status:** Aceita; portada para a candidata pública 3.0.0.
- **Data:** 2026-11-08

## Contexto

Abrir programas no modo Xbox deve dispensar a ida ao desktop.

## Decisão

Programas usa o índice do Menu Iniciar, pesquisa sem acentos, histórico de uso e teclado embutido. Resultados são limitados, ícones carregam fora da UI e a abertura usa o Explorer para evitar herdar elevação, salvo escolha explícita. A aceitação do pedido não confirma que uma janela abriu.

## Validação e limites

A build pública mantém produto e testes separados. Suítes com substitutos não comprovam controle, TV, Steam, áudio ou energia físicos. A publicação no GitHub e a matriz física permanecem pendentes. Ver [comparação e validação do porte](../atualizacao-publica-2026-11-08.md).
