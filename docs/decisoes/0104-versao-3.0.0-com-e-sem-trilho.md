# 0104 — Versão 3.0.0 com e sem trilho

- **Status:** Aceita; portada para a candidata pública 3.0.0.
- **Data:** 2026-11-08

## Contexto

Os dois layouts compartilham o mesmo produto.

## Decisão

Usar a mesma versão e o mesmo executável para os layouts. O marcador TITULO-DESLIZANTE.txt é compatibilidade de primeira abertura; a ADR 0112 substitui a necessidade de duas distribuições por uma preferência.

## Validação e limites

A build pública mantém produto e testes separados. Suítes com substitutos não comprovam controle, TV, Steam, áudio ou energia físicos. A publicação no GitHub e a matriz física permanecem pendentes. Ver [comparação e validação do porte](../atualizacao-publica-2026-11-08.md).
