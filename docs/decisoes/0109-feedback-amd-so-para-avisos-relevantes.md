# 0109 — Feedback AMD discreto nas operações rotineiras

- **Status:** Aceita; portada para a candidata pública 3.0.0.
- **Data:** 2026-11-08

## Contexto

Mensagens de sucesso rotineiro encobrem avisos mais úteis.

## Decisão

Guardar sucessos rotineiros no histórico e log. Erros, recusas, resultado não confirmado, mudanças adicionais do driver e manutenção do cache continuam visíveis. Uma operação silenciosa não apaga o erro em exibição.

## Validação e limites

A build pública mantém produto e testes separados. Suítes com substitutos não comprovam controle, TV, Steam, áudio ou energia físicos. A publicação no GitHub e a matriz física permanecem pendentes. Ver [comparação e validação do porte](../atualizacao-publica-2026-11-08.md).
